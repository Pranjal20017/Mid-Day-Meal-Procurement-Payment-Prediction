Introduction & Domain Background

PM POSHAN Scheme

Formerly known as the Mid-Day Meal Scheme, providing vital nutritional support to millions of school children across India.

Food Grain Procurement

Continuous bulk purchasing of foundational commodities (Wheat, Rice, Dal, Oil) from various localized vendors.

Financial Lifecycle

Payments undergo administrative review. Pending payments risk disrupting supply chains and causing vendor friction.

Dataset Provenance

Data retrieved from procurement administrative records (track4_mid_day_meal_procurement.xlsx). Contains transactional attributes including order timestamps, vendor identities, raw commodity text descriptions, quantity counts, total invoiced amounts, and final settlement statuses.

Problem Statement & Objectives

The Problem

  • Payment Bottlenecks: Unpredictable delays in invoice clearances strain small vendor operations.
  • Supply Interruptions: Key nutritional deliveries get stalled when vendor liabilities pile up without visibility.
  • Manual Overheads: Traditional audit processes lack early anomaly detection for pending clearances.

Key Objectives

  • Predictive Modeling: Formulate a Supervised Binary Classifier targeting Payment Status (Paid = 1, Pending = 0).
  • Data Refinement: Build regex cleaning functions for corrupted financial text strings.
  • Operational Predictor: Deploy an interactive tool to estimate settlement probability for new invoices.

Data Cleaning & Regex Standardization

Raw Data Inconsistencies

Invoices contain mixed formatting such as currency symbols (₹12,500), stray text units (500 kg), and inconsistent date stamps.

Raw Total Cost: "₹ 45,000.00 /-"
Raw Quantity: "1,200 (bags)"
Raw Grain Type: "GEHUN / Atta Grade-A"

Regex Extraction Pipeline

Python’s re.sub(r'[^\d.]', '', val) strips all non-numeric tokens, safely casting values into clean float64 format.

Cleaned Cost: 45000.00 (float)
Cleaned Quantity: 1200.00 (float)
Standardized Grain: "Wheat" (categorical)
Python Implementation Snippet: 
def clean_cost(val):
    if pd.isna(val): return np.nan
    val_clean = re.sub(r'[^\d.]', '', str(val).replace(',', ''))
    try: return float(val_clean)
    except: return np.nan

Slide 07

Machine Learning Pipeline Setup

01. ENCODING

LabelEncoder

Converts vendor string labels & grain names into discrete numeric codes.

02. IMPUTATION

SimpleImputer

Fills missing values using column median strategy to prevent bias.

03. SPLITTING

80/20 Stratified Split

Maintains exact class proportions across training and test partitions.

04. SCALING

StandardScaler

Transforms numerical features to zero mean ($\mu=0$) and unit variance ($\sigma=1$).

Why Feature Scaling is Crucial for Distance-Based Algorithms:

Features like clean_cost span tens of thousands, whereas time features like month span 1 to 12. Without scaling, Euclidean distance calculations in KNN and margin optimizations in SVM / Logistic Regression would be completely dominated by cost magnitude.
